# Doctor

Diagnostics, integrity checks, installation-state inspection, and repair guidance belong here.

Doctor should aggregate non-destructive health signals from:

- framework and schema versions;
- capability catalog integrity;
- adapter/model catalog state;
- MCP inventory and drift;
- security scan state;
- active session/worktree state;
- generated projection drift;
- available validation capability.

Doctor operations are safe by default and clearly distinguish inspection from mutation.
