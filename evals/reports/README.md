# Eval Reports

Reports compare a candidate execution against an applicable baseline.

A report should identify:

- evaluated framework version;
- baseline identity;
- eval cases executed;
- regressions;
- improvements;
- inconclusive changes;
- routing or cost changes;
- evidence gaps.

A better aggregate score must not hide a hard permission, privacy, mutation, or security failure.
