# Eval Baselines

Baselines capture a privacy-safe reference result for a stable eval set and framework version.

A baseline may record:

- eval set identity;
- framework version or commit;
- route/catalog version;
- success and first-pass success rates;
- retry, fallback, and escalation counts;
- validation and review outcomes;
- wall-time summaries;
- API/token usage summaries when available.

Baselines must not store prompts, source excerpts, diffs, credentials, raw reasoning, or protected implementation content.
