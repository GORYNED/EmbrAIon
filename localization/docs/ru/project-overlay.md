# Project Overlay (Проектный слой)

Подключаемый репозиторий явно подключается к EmbrAIon через `.embraion/project.yaml`.

Проектный слой хранит:

- объявленный репозиторий EmbrAIon и версию системы;
- идентичность проекта;
- расположение проектных знаний;
- специфичных для проекта агентов;
- внешние возможности.

Проектный слой может добавлять более строгие правила, но не должен скрытно ослаблять жёсткие ограничения Core (Ядра).

## Текущее поведение версий в v0.1.x

`embraion init` записывает в `.embraion/project.yaml` версию системы, которую предоставляет текущая запущенная установка EmbrAIon.

Текущая реализация `v0.1.x` не выбирает эту записанную версию автоматически при последующем запуске `install` или `sync`. Эти команды генерируют представления из данных системы, доступных текущему запущенному CLI. Поэтому поле версии сейчас является декларацией совместимости проекта и явной границей обновления, но пока не является автоматическим механизмом выбора runtime-версии для каждого проекта.

Для точной воспроизводимости используйте ту версию CLI/системы, которая совпадает с версией, записанной в проекте.

Сам репозиторий проекта остаётся каноническим источником продуктовой спецификации, архитектуры, контрактов совместимости, результатов валидации и предметных знаний.
