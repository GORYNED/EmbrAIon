# План выделения системы

**Framework (Система)** следует отделять от существующих проектов недеструктивно.

## Последовательность

1. Провести аудит переиспользуемых и специфичных для проекта материалов.
2. Зафиксировать каноническую структуру EmbrAIon.
3. Выделить переиспользуемые возможности в отдельный верхнеуровневый репозиторий.
4. Там, где это практически оправдано, временно поддерживать старые и новые пути до завершения проверки эквивалентности.
5. Проверить эквивалентность поведения, маршрутизации, ревью и инструментов.
6. Перевести подключаемые проекты на версионируемую систему.
7. Удалять устаревшие дубли только после подтверждения эквивалентности.

Цель — не выполнять разрушительные переносы до тех пор, пока границы владения не доказаны.
