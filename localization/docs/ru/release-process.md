# Процесс релизов

EmbrAIon использует версионируемые релизы системы.

Предполагаемый контракт:

- GitHub является источником истины.
- Релизы EmbrAIon получают теги Git и сопровождаются документацией.
- Новые проекты создаются на основе опубликованной версии.
- Существующие проекты фиксируют конкретную версию EmbrAIon в `.embraion/project.yaml`.
- Глобальный launcher автоматически разрешает опубликованный pin в изолированный runtime, закэшированный в `~/.embraion/versions/`.
- Обновления выполняются намеренно, с описанием изменений и обязательной валидацией; `embraion update` меняет только pin текущего проекта.

Сейчас репозиторий находится в предстабильном состоянии. Процесс релизов будет дополнительно усилен до публикации первой стабильной версии.
