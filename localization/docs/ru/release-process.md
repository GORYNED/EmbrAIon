# Процесс релизов

EmbrAIon использует versioned framework releases.

Предполагаемый контракт:

- GitHub — source of truth.
- Framework releases получают tags и документацию.
- Новые проекты bootstrap из released version.
- Существующие проекты pin конкретную версию framework.
- Updates выполняются намеренно, с release notes и validation.

Сейчас repository находится в pre-stable состоянии; release process будет усилен до первой stable версии.
