# Routing (Маршрутизация моделей)

Маршрутизация — возможность первого класса в EmbrAIon.

Канонические правила маршрутизации определяют, как характеристики задачи преобразуются в выбор модели и провайдера, уровень рассуждения, разрешения на выполнение, эскалацию и требования к ревью.

Адаптеры провайдеров реализуют технический вызов модели, но не определяют канонические правила принятия решения.

Подробные контракты маршрутизации версионируются отдельно по мере развития EmbrAIon.
