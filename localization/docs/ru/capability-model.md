# Модель возможностей

**Capability (Возможность)** — отдельная часть EmbrAIon с чётко определённой ответственностью.

EmbrAIon использует явные типы возможностей, чтобы не смешивать правила, ответственность, процедуры, порядок выполнения и фактические знания.

| Тип | Назначение |
| --- | --- |
| **Rule (Правило)** | Обязательное, запрещённое или защищённое поведение |
| **Agent (Агент)** | Ответственность и область владения |
| **Skill (Навык)** | Повторяемая процедура |
| **Workflow (Рабочий процесс)** | Упорядоченная последовательность действий |
| **Routing (Маршрутизация)** | Выбор модели, провайдера, уровня рассуждения и режима выполнения |
| **Tool (Инструмент)** | Детерминированная операция |
| **Adapter (Адаптер)** | Интеграция с конкретным клиентом или провайдером |
| **Knowledge (Знания)** | Факты и архитектурные сведения |

У каждой канонической возможности должен быть один основной тип. Если несколько возможностей связаны между собой, предпочтительнее использовать перекрёстные ссылки, а не дублировать один и тот же текст в разных местах.
