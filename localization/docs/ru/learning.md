# Learning (Обучение)

Обучение EmbrAIon основано на доказательствах и ограничено правилами управления системой.

Система может собирать безопасные наблюдения из среды выполнения, валидации, ревью и поведенческих проверок. Повторяющиеся доказательства могут сформировать кандидата на новую или улучшенную возможность: правило, навык, рабочий процесс, настройку маршрутизации, запись знаний или проверочный сценарий.

Ни один кандидат не становится канонической частью EmbrAIon автоматически.

Продвижение кандидата проходит через рабочий процесс обучения и обычные инженерные ограничения: ревью, валидацию, подходящее покрытие поведенческими проверками и явное одобрение.
