# Обучение

Learning в EmbrAIon основан на evidence и ограничен governance.

Система может собирать privacy-safe наблюдения из runtime, validation, review и eval outcomes. Повторяющиеся evidence могут стать candidate для reusable rule, skill, workflow, routing adjustment, knowledge entry или eval.

Ни один candidate не становится canonical автоматически.

Promotion следует Core Learning workflow и обычным engineering controls: review, validation, подходящее eval coverage и explicit approval.
