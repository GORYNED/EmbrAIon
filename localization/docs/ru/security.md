# Security (Безопасность)

EmbrAIon рассматривает разрешения на выполнение, классификацию данных, допустимость провайдера, внешние интеграции, сгенерированную конфигурацию, учётные данные и права на изменение как обязательные инженерные ограничения.

Правила безопасности находятся в правилах и маршрутизации ядра. Адаптеры конкретных клиентов и провайдеров реализуют необходимые механизмы. `tools/security/` выполняет детерминированную проверку, а `tools/mcp/` нормализует инвентаризацию внешних серверов и обнаружение расхождений.

**Fail Closed (Безопасный отказ)** применяется, если:

- задачу невозможно безопасно классифицировать;
- провайдер не разрешён для соответствующего класса данных;
- внешняя интеграция имеет неизвестный или неожиданно расширенный доступ;
- секрет попал в сохраняемую конфигурацию;
- сгенерированная конфигурация расходится с утверждённым источником;
- действие с правом записи выходит за пределы своего профиля доступа.

Результаты проверки безопасности являются доказательством проблемы, а не разрешением ослабить управляющее правило.
