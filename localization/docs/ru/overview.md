# Обзор

EmbrAIon — переиспользуемая **AI-First Engineering System (AI-First инженерная система)**.

**Core (Ядро)** использует агентов с названиями ролей-должностей, правила по типам возможностей, ориентированную на тип задачи model-agnostic маршрутизацию и детерминированные инструменты. EmbrAIon не владеет актуальными названиями моделей: доступность и default/automatic выбор принадлежат AI-клиенту, а проект при необходимости хранит только свои host-specific overrides.

Это позволяет EmbrAIon развиваться без привязки к Codex, GitHub Copilot, Claude Code, конкретному провайдеру или поколению моделей.

Spec Kit рекомендуется как внешнее дополнение для существенной работы, где требуется формальная спецификация.

Подключаемый репозиторий добавляет собственные предметные знания, ограничения и необязательные routing overrides через **Project Overlay (Проектный слой)**.
