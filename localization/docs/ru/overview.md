# Обзор

EmbrAIon — переиспользуемая AI-First Engineering System.

Core использует агентов с названиями ролей-должностей, policy по типам capabilities, provider-neutral routing и детерминированные tools. Факты о конкретных hosts и моделях изолированы в adapters, поэтому framework может развиваться без привязки к Codex, Copilot, Claude Code или одному provider.

Spec Kit рекомендуется как внешняя дополнительная capability для substantial specification-driven работы.

Подключаемый репозиторий добавляет собственную доменную истину через project overlay.
