# Обзор

EmbrAIon — переиспользуемая **AI-First Engineering System (AI-First инженерная система)**.

**Core (Ядро)** использует агентов с названиями ролей-должностей, правила по типам возможностей, независимую от провайдера маршрутизацию и детерминированные инструменты. Сведения о конкретных клиентах и моделях изолированы в **Adapters (Адаптерах)**, поэтому EmbrAIon может развиваться без привязки к Codex, GitHub Copilot, Claude Code или одному конкретному провайдеру.

Spec Kit рекомендуется как внешнее дополнение для существенной работы, где требуется формальная спецификация.

Подключаемый репозиторий добавляет собственные предметные знания и ограничения через **Project Overlay (Проектный слой)**.
