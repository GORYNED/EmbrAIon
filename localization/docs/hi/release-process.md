# रिलीज़ प्रक्रिया

EmbrAIon संस्करणबद्ध सिस्टम रिलीज़ उपयोग करता है।

अपेक्षित नियम:

- GitHub सत्य का स्रोत है।
- EmbrAIon रिलीज़ को Git tag और दस्तावेज़ मिलते हैं।
- नए प्रोजेक्ट प्रकाशित संस्करण से शुरू होते हैं।
- मौजूदा प्रोजेक्ट `.embraion/project.yaml` में किसी स्पष्ट EmbrAIon संस्करण को निश्चित करते हैं।
- वैश्विक launcher प्रकाशित pin को `~/.embraion/versions/` में अलग runtime के रूप में अपने आप resolve करता है।
- अपडेट जानबूझकर, परिवर्तन विवरण और सत्यापन के साथ किए जाते हैं; `embraion update` केवल वर्तमान प्रोजेक्ट का pin बदलता है।

रिपॉजिटरी अभी स्थिर संस्करण से पहले की अवस्था में है। पहला स्थिर रिलीज़ प्रकाशित होने से पहले रिलीज़ प्रक्रिया और मजबूत की जाएगी।
