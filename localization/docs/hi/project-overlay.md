# Project Overlay (प्रोजेक्ट ओवरले)

EmbrAIon उपयोग करने वाली रिपॉजिटरी `.embraion/project.yaml` के माध्यम से स्पष्ट रूप से सिस्टम से जुड़ती है।

प्रोजेक्ट ओवरले दर्ज करता है:

- घोषित EmbrAIon रिपॉजिटरी और सिस्टम संस्करण;
- प्रोजेक्ट की पहचान;
- प्रोजेक्ट ज्ञान का स्थान;
- प्रोजेक्ट-विशिष्ट Agent (एजेंट);
- बाहरी क्षमताएँ।

प्रोजेक्ट ओवरले अधिक कठोर नियम जोड़ सकता है, लेकिन Core की अनिवार्य सीमाओं को चुपचाप कमज़ोर नहीं कर सकता।

## v0.1.x में वर्तमान संस्करण व्यवहार

`embraion init` वर्तमान में चल रही EmbrAIon स्थापना द्वारा उपलब्ध सिस्टम संस्करण को `.embraion/project.yaml` में लिखता है।

वर्तमान `v0.1.x` कार्यान्वयन बाद में `install` या `sync` चलाते समय उस दर्ज संस्करण को अपने आप resolve नहीं करता। ये कमांड वर्तमान में चल रहे CLI को उपलब्ध सिस्टम डेटा से प्रस्तुतिकरण बनाते हैं। इसलिए संस्करण फ़ील्ड अभी प्रोजेक्ट संगतता की घोषणा और स्पष्ट अपडेट सीमा है, स्वचालित प्रति-प्रोजेक्ट runtime resolver नहीं।

सटीक पुनरुत्पादन के लिए वही CLI/सिस्टम वितरण चलाएँ जो प्रोजेक्ट में दर्ज संस्करण से मेल खाता हो।

प्रोजेक्ट रिपॉजिटरी स्वयं उत्पाद विनिर्देशन, वास्तुकला, संगतता अनुबंध, सत्यापन प्रमाण और डोमेन ज्ञान का मानक स्रोत बनी रहती है।
