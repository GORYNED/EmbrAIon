# Spec Kit

Spec Kit EmbrAIon के लिए अनुशंसित बाहरी सहायक है।

जब महत्वपूर्ण सुविधा कार्य को स्पष्ट विनिर्देशन, आवश्यकताओं की स्पष्टता, योजना, कार्य-विभाजन, जाँच-सूची या कार्यान्वयन प्रगति ट्रैकिंग से लाभ हो, तब Spec Kit उपयोग करें।

Spec Kit की आंतरिक फ़ाइलें EmbrAIon Core में कॉपी न करें। इसे स्वतंत्र रूप से अपडेट होने दें और दस्तावेज़ित कार्यप्रवाह या क्लाइंट एडाप्टर के माध्यम से जोड़ें।

Spec Kit की सामग्री काम को स्पष्ट कर सकती है, लेकिन यह निम्न को नहीं बदलती:

- EmbrAIon Core के नियम;
- प्रोजेक्ट वास्तुकला;
- उत्पाद तथ्य-स्रोत;
- संगतता अनुबंध;
- सत्यापन प्रमाण;
- सक्षम होने पर मानव merge आवश्यकता।
