# अवलोकन

EmbrAIon एक पुन: उपयोग योग्य **AI-First Engineering System (AI-प्रथम इंजीनियरिंग सिस्टम)** है।

**Core (केंद्र)** भूमिका-आधारित एजेंट, क्षमता-प्रकार आधारित नियम, प्रदाता-स्वतंत्र रूटिंग और निर्धारक उपकरण उपयोग करता है। विशिष्ट क्लाइंट और मॉडल संबंधी जानकारी **Adapters (एडाप्टर)** में अलग रखी जाती है, इसलिए EmbrAIon Codex, GitHub Copilot, Claude Code या किसी एक प्रदाता से बँधे बिना विकसित हो सकता है।

Spec Kit उन महत्वपूर्ण कार्यों के लिए अनुशंसित बाहरी सहायक है जहाँ औपचारिक विनिर्देशन उपयोगी हो।

EmbrAIon उपयोग करने वाली रिपॉजिटरी अपना डोमेन ज्ञान और सीमाएँ **Project Overlay (प्रोजेक्ट ओवरले)** के माध्यम से जोड़ती है।
