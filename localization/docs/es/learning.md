# Learning (Aprendizaje)

El aprendizaje de EmbrAIon está basado en evidencia y limitado por reglas de gobierno del sistema.

El sistema puede recopilar observaciones seguras de la ejecución, validación, revisión y evaluaciones de comportamiento. La evidencia repetida puede generar un candidato para una regla, habilidad, flujo, ajuste de enrutamiento, entrada de conocimiento o escenario de evaluación nuevo o mejorado.

Ningún candidato se convierte automáticamente en parte canónica de EmbrAIon.

La promoción de un candidato requiere revisión, validación, cobertura adecuada de evaluaciones de comportamiento y aprobación explícita.
