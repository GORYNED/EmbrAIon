# Spec Kit

Spec Kit es un complemento externo recomendado para EmbrAIon.

Utilícelo cuando un trabajo importante se beneficie de una especificación explícita, aclaración de requisitos, planificación, división de tareas, listas de comprobación o seguimiento de implementación.

No copie los archivos internos de Spec Kit al Core de EmbrAIon. Debe poder actualizarse de forma independiente y conectarse mediante flujos documentados o adaptadores de cliente.

El material producido por Spec Kit puede precisar el trabajo, pero no sustituye:

- las reglas del Core de EmbrAIon;
- la arquitectura del proyecto;
- la fuente de verdad del producto;
- los contratos de compatibilidad;
- la evidencia de validación;
- el requisito de merge humano cuando esté activado.
