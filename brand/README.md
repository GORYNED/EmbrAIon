# EmbrAIon Brand

Git is the canonical source of truth for versioned brand copy, usage rules and the approved logo and banner files.

## Contents

- [`copy.yaml`](copy.yaml) — canonical reusable brand strings.
- [`identity.md`](identity.md) — naming, meaning, logo, and visual identity rules.
- [`voice.md`](voice.md) — writing and tone guidelines.
- [`publishing/assets/`](../publishing/assets/) — approved logos and banners (icon, README hero, GitHub social; light and dark); the folder also feeds the project page on goryned.com.

Other production formats (portrait, story, square and horizontal logo) are added here only when a concrete repository use case requires them.
