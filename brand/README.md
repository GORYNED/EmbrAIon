# EmbrAIon Brand

Git is the canonical source of truth for versioned brand copy and usage rules. Figma is the visual design workspace and source for approved visual composition.

[Figma · EmbrAIon Branding](https://www.figma.com/design/gFnhyyJqR1PaeuumuIHQ5Q/Branding)

## Contents

- [`copy.yaml`](copy.yaml) — canonical reusable brand strings.
- [`identity.md`](identity.md) — naming, meaning, logo, and visual identity rules.
- [`voice.md`](voice.md) — writing and tone guidelines.
- [`assets/readme/`](assets/readme/) — only approved assets required by repository README files.

Production exports for social, presentation, or product use remain in the design workspace unless a concrete repository use case requires them.
