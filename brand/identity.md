# Brand Identity

## Name

Always write **EmbrAIon** with `AI` capitalized.

Pronunciation: **Em-brAI-on** / **Эмбрайон**.

## Meaning

The name intentionally combines three ideas:

- **Ember** — a spark, heat, and the beginning of fire.
- **AI** — intelligence embedded directly into the engineering system.
- **Embryo** — formation, birth, and growth from an initial idea into a living project.

EmbrAIon is created by **[GORYNED](https://goryned.com)**.

## Primary identity

- Category: **AI-First Engineering System**
- Primary tagline: **Where sparks become AI-built products**
- Byline: **[by GORYNED](https://goryned.com)**

Use **AI-First Engineering System** in prose, metadata, headings, labels, and repository text. The all-caps form **AI-FIRST ENGINEERING SYSTEM** is reserved for graphical banners and brand artwork only.

Headlines, taglines, and labels are written without terminal periods. Full descriptive sentences use normal punctuation.

## Visual direction

The identity uses dark neutral surfaces with ember-orange and amber accents. Fire belongs primarily to the brand layer; engineering documentation should use precise technical terminology rather than decorative fire metaphors.

The Figma branding file is the canonical visual workspace. Repository assets are intentionally limited to files required by README rendering.
