# Learning

Learning в EmbrAIon основан на evidence и контролируется governance.

Система может собирать privacy-safe observations из runtime, validation, review и eval outcomes. Повторяющееся evidence может стать candidate для reusable rule, skill, workflow, routing adjustment, knowledge entry или eval.

Ни один candidate не становится canonical автоматически.

Promotion следует Core Learning workflow и обычным engineering controls: review, validation, appropriate eval coverage и explicit approval.

[Поддержка знаний](guides/knowledge-maintenance.ru.md) сравнивает явные связи документов и исходников с проверенным локальным baseline. Изменение означает необходимость review, а не автоматическую правку документа или продвижение правила. [Создание skills](guides/engineering-skills.ru.md) использует целевые детерминированные проверки и подходящие live cases перед продвижением кандидата. Свежесть checkpoint не восстанавливает устаревшее подтверждение Reviewer.
