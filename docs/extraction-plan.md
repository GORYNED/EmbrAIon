# Extraction Plan

The framework should be separated from existing projects non-destructively.

## Sequence

1. Audit existing reusable and project-specific material.
2. Establish the EmbrAIon canonical structure.
3. Copy/extract reusable capabilities upstream.
4. Keep old and new paths operational during parity validation where practical.
5. Validate behavior, routing, review, and tooling parity.
6. Cut consuming projects over to the versioned framework.
7. Remove duplicated legacy definitions only after parity is demonstrated.

The goal is to avoid destructive moves before the ownership boundary is proven.
