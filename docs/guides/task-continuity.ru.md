# Непрерывность задачи

Контрольная точка сохраняет краткие ссылки для продолжения прерванной задачи. Локальные файлы находятся в игнорируемом каталоге `.embraion/state/checkpoints/`. Укажите уникальный ID точки, ID задачи, этап (`planning`, `implementing`, `validating`, `reviewing`, `blocked` или `complete`), при необходимости ID решения и следующего действия. Критерии приёмки и оставшиеся задачи задаются путями относительно проекта. Для подробностей используйте отдельные файлы; не включайте в ID запросы, исходный код, различия файлов, секреты или личные пояснения.

API Python: `create_checkpoint(checkpoint_id, *, task_id, phase, decision_id=None, next_action_id=None, acceptance_path=None, remaining_path=None, context_id=None, run_id=None, project=None)`. Сохраняются хеши `.embraion/project.yaml`, `.embraion/knowledge.yaml`, файлов задачи, записи контекста и выбранных ею документов, записи выполнения и свидетельств проверки. Также сохраняется существующий снимок Git для проверки: HEAD, индекс и видимые Git рабочие файлы, включая неотслеживаемые. При отсутствии обязательного файла создание прекращается. Без доступного снимка Git точку можно записать, но нельзя признать актуальной при продолжении.

`resume_checkpoint(checkpoint_id, *, project=None)` только читает данные и возвращает `valid`, `stale` или `missing`, причины, изменённые или отсутствующие опоры и пути к свидетельствам. Выполнение автоматически не возобновляется. Изменение снимка Git делает прежние выводы устаревшими. Перед продолжением проверьте изменённую работу и свидетельства. Результат не даёт разрешения пользователя или одобрения независимой проверки. Ранее данное разрешение подтверждается доверенной исходной сессией, а не контрольной точкой.

ID и пути проверяются против выхода из проекта и символьных ссылок. Сохраняются только относительные пути и хеши. Локальный каталог состояния игнорируется Git и защищается согласно правилам проекта. Статус устаревания служит подсказкой для дальнейшей работы, но не автоматическим одобрением или продвижением.
