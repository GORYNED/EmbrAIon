# Spec Kit

Spec Kit is a recommended external companion to EmbrAIon.

Use it when substantial feature work benefits from explicit specification, clarification, planning, task decomposition, checklists, or implementation tracking.

Do not copy upstream Spec Kit internals into EmbrAIon Core. Keep it independently updatable and integrate through documented workflows or host adapters.

Spec Kit artifacts refine work but do not override:

- EmbrAIon Core rules;
- project architecture;
- product truth;
- compatibility contracts;
- validation evidence;
- human merge gates.
