# Support

Supported operating-system families:

- Windows
- macOS
- Linux

EmbrAIon requires Python 3.11 or newer. Release compatibility CI currently gates the minimum Python version and the selected latest Python version across all three operating-system families.

Before 1.0:

- patch releases are intended for compatible fixes and improvements;
- minor releases may evolve public framework contracts;
- project version pinning keeps older consumers reproducible until they intentionally migrate.

The canonical policy is [SUPPORT.md](https://github.com/GORYNED/EmbrAIon/blob/main/SUPPORT.md).
