# Governance

EmbrAIon is maintained by GORYNED.

The current model is intentionally simple:

- GORYNED is the upstream maintainer and final decision-maker;
- external contributors propose changes through Pull Requests;
- maintainer-authored changes may go directly to `main`;
- validation is the evidence gate;
- accepted external Pull Requests use Squash merge;
- published `vX.Y.Z` release tags are intended to remain immutable.

The canonical policy is [GOVERNANCE.md](https://github.com/GORYNED/EmbrAIon/blob/main/GOVERNANCE.md).
