# Поддержка

Поддерживаемые семейства operating systems:

- Windows
- macOS
- Linux

EmbrAIon требует Python 3.11 или новее. Release compatibility CI проверяет минимальную и выбранную latest Python version на всех трёх OS families.

До 1.0:

- patch releases предназначены для compatible fixes и improvements;
- minor releases могут развивать public framework contracts;
- project version pinning сохраняет воспроизводимость старых consumers до их намеренной migration.

Каноническая policy: [SUPPORT.md](https://github.com/GORYNED/EmbrAIon/blob/main/SUPPORT.md).
