# Governance

EmbrAIon поддерживается GORYNED.

Текущая модель намеренно простая:

- GORYNED — upstream maintainer и final decision-maker;
- external contributors предлагают изменения через Pull Requests;
- maintainer-authored changes могут попадать прямо в `main`;
- validation является evidence gate;
- accepted external Pull Requests используют Squash merge;
- опубликованные `vX.Y.Z` release tags должны оставаться immutable.

Каноническая policy: [GOVERNANCE.md](https://github.com/GORYNED/EmbrAIon/blob/main/GOVERNANCE.md).
