# Open Source

EmbrAIon разрабатывается публично по лёгкой maintainer-led governance model.

Исходный код и документация лицензируются по MIT, если явно не указано иное. Права на бренд и trademarks регулируются отдельно.

Канонические policy files остаются в корне репозитория. Эти страницы объясняют, как ими пользоваться:

- [Участие в разработке](contributing.md)
- [Поддержка](support.md)
- [Сообщение об уязвимостях](security-reporting.md)
- [Governance](governance.md)
- [Лицензирование](../licensing.md)
