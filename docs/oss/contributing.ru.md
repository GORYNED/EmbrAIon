# Участие в разработке

Внешние contributions принимаются через forks и Pull Requests.

Основные требования:

- один Pull Request должен иметь одну coherent purpose;
- сохраняйте разделение Core/adapter;
- не переносите project-specific semantics в reusable Core;
- добавляйте deterministic tests, когда меняется deterministic behavior;
- документируйте изменения public behavior;
- не включайте secrets, credentials или private data;
- для принятых external contributions используйте Squash merge.

Contributor License Agreement не требуется.

Каноническая policy: [CONTRIBUTING.md](https://github.com/GORYNED/EmbrAIon/blob/main/CONTRIBUTING.md).
