# Сообщение об уязвимостях

Не раскрывайте exploitable vulnerability через public Issue, Pull Request или Discussion.

Используйте GitHub Private Vulnerability Reporting:

**[Сообщить об уязвимости приватно](https://github.com/GORYNED/EmbrAIon/security/advisories/new)**

Полезный report включает affected version, environment, impact, reproducible steps и информацию о том, затрагиваются ли credentials, private data или code execution.

Каноническая policy: [SECURITY.md](https://github.com/GORYNED/EmbrAIon/blob/main/SECURITY.md).

Technical security model framework описана в [Безопасности](../security.md).
