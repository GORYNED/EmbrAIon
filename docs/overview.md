# Overview

EmbrAIon is a reusable AI-First Engineering System.

Its Core uses job-like agents, capability-typed policy, provider-neutral routing, and deterministic tooling. Host/model facts are isolated in adapters so the framework can evolve without tying its canonical behavior to Codex, Copilot, or one provider.

Spec Kit is a recommended external companion for substantial specification-driven work.

A consuming repository contributes its domain truth through a project overlay.
