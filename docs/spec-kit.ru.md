# Spec Kit

Spec Kit — рекомендуемый external companion для EmbrAIon.

Используйте его, когда substantial feature work выигрывает от explicit specification, clarification, planning, task decomposition, checklists или implementation tracking.

Не копируйте upstream Spec Kit internals в EmbrAIon Core. Держите его independently updatable и интегрируйте через documented workflows или host adapters.

Spec Kit artifacts уточняют работу, но не переопределяют:

- EmbrAIon Core rules;
- project architecture;
- product truth;
- compatibility contracts;
- validation evidence;
- human merge gates.
