# Workflows

Workflows compose rules, agents, skills, routing, validation, and review into ordered execution.

Current foundation workflows:

- `engineering.md` — end-to-end substantial engineering.
- `review.md` — independent review and remediation cycle.
- `delivery.md` — handoff and human merge gate.
- `worktree.md` — isolated-task workflow.
- `git.md` — Git and GitHub mechanics for the worktree and delivery workflows; a reference, not a workflow.
- `learning.md` — evidence-driven proposal and reviewed capability promotion.

Spec Kit is a recommended planning/specification companion inside substantial engineering, not a replacement for the workflow.
