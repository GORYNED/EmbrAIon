# LiteLLM

LiteLLM is a transport adapter, not a model catalog owner.

It may implement provider-neutral loopback transport, request normalization, provider evidence capture, and cost/usage reconciliation. Canonical model identity stays in each provider's `models.yaml`, while provider eligibility and route policy stay outside the transport.
