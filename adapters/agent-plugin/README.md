# Agent Plugin

This adapter packages canonical EmbrAIon capabilities into a portable installable agent bundle.

The package is generated from Core and adapter metadata. The generated package is not the canonical source of rules, agents, skills, workflows, or routing.

Responsibilities:

- include discoverable skills;
- expose capability metadata;
- reference optional tool/server integrations;
- keep host-specific extensions isolated;
- preserve one canonical source of truth in EmbrAIon Core.
