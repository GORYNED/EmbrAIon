# Templates

Templates bootstrap consuming projects without copying EmbrAIon Core into each repository.

A project should keep only its overlay, local domain knowledge, and project-specific capabilities in-repository.

`pull-request/` holds an optional, project-neutral pull request template. `embraion pr-template` installs it and never overwrites an existing template.
