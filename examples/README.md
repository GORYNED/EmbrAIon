# Reference Projects

Reference projects demonstrate how EmbrAIon composes with real repository shapes without becoming canonical policy.

The examples are intentionally public, generic, and free of product-specific or private project semantics.

- [Minimal](minimal/README.md) — the smallest project overlay and project knowledge.
- [Python](python/README.md) — a small Python package with ordinary unit tests plus EmbrAIon.
- [Unity](unity/README.md) — a generic Unity 6 / C# project with an assembly definition, pure state logic, a Unity controller, and project architecture knowledge.

CI copies these projects into temporary directories and exercises their EmbrAIon lifecycle. Generated host projections are not committed into the examples because they are disposable outputs.
