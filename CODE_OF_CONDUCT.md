# Code of Conduct

EmbrAIon project spaces are for constructive technical collaboration.

## Expected behavior

- Be professional and respectful.
- Discuss code, design, evidence, and technical decisions rather than attacking people.
- Keep feedback specific, actionable, and relevant to the project.
- Respect privacy and do not publish another person's private information.

## Unacceptable behavior

The following is not acceptable in Issues, Pull Requests, reviews, or other project spaces:

- harassment, threats, intimidation, or personal attacks;
- discrimination or degrading comments;
- doxxing or publication of private information;
- deliberate spam, disruption, or bad-faith participation;
- repeated behavior intended to derail technical discussion.

## Enforcement

GORYNED maintains the project and may edit or remove content, close or lock Issues and Pull Requests, reject contributions, or restrict participation when necessary to protect the project and its participants.

If a conduct concern involves sensitive personal information, do not post that information publicly. Use an appropriate private GitHub contact path when available.

These rules apply to participation in EmbrAIon project spaces and project-related representation.
