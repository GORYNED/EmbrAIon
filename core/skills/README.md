# Skills

Skills are reusable procedures used by job-like agents.

Current foundation skills:

- `planning.md`
- `implementation.md`
- `validation.md`
- `review.md`
- `research.md`

A skill describes **how** to perform a class of work. It does not own model selection or host-specific syntax.
