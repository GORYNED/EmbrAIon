EmbrAIon хранит правила AI-разработки вместе с репозиторием: знания проекта, защищённые пути, routing, validation, review и evidence, вместо того чтобы разбрасывать их по prompt-ам и настройкам AI-клиентов. Один и тот же контракт проекта можно использовать с Codex, GitHub Copilot, Claude Code или host-neutral Portable bundle.

## Когда это нужно

- Важные правила проекта уже не помещаются в один prompt.
- Несколько AI-клиентов должны следовать одному контракту репозитория.
- Защищённым путям и проверкам нужны детерминированные проверки, а не только текст.
- Знания об архитектуре и политика должны переживать смену модели и сессии.
- Выбор модели, review и evidence должны быть переиспользуемыми настройками проекта, а не разовыми решениями.

EmbrAIon не заменяет AI-клиент, не перехватывает каждый prompt и не работает внутри готового продукта.
